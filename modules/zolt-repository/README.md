# zolt-repository

Fetches Maven repository metadata and artifacts, manages repository-scoped
indexes over content-addressed artifact blobs, retains selected-source
provenance, provides artifact bytes for lockfile-pinned SHA-256 integrity, and
coordinates concurrent downloads.

This is an internal workspace module. User-facing workflows are documented in
the root [README](../../README.md) and [USAGE.md](../../USAGE.md).
